How to get a Google AI key
  1. Open aistudio.google.com and sign in with your Google account.
  2. Tap Get API key, then Create API key.
  3. Tap Set up billing for the key and add a payment card (image AI is paid: about ₹3.5–₹11 per photo).
  4. Copy the key, come back here, paste it above and tap Save and check key.

Photos you send to the AI are processed by Google. Use it only with the customer's permission.
